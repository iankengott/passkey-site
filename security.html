Security

Where it is stronger, and where it is not.

Nothing syncs, so it beats Google Password Manager on account takeover and a sync breach. It keeps saved logins off a stolen laptop when the key is removed. A hardware passkey beats it on four. Passwords can be phished or read by a breached site, though passkey mode closes that gap where a site accepts it. The computer shows the approval, so malware on it can mislead you. Nothing stops someone holding the key.

USB-A contacts

One small light, flush with the cover. It shows the key is working. It is not a security display: the approval prompt is on your screen.
No button here
No button, no touch pad, no PIN pad and no fingerprint reader. You approve each login in a prompt on the screen. That keeps it quick, and it is the main trade-off.
